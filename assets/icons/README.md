# Peter UI Assets & Branding

This folder is the dedicated space for all graphical assets, logos, and custom UI elements used in the Peter application.

## 🎨 Adding Your Custom Logo

When you finish designing your logo, please convert it to an `.ico` file and place it right here in this folder. 

**Target File Name:** `peter.ico`
**Path:** `assets/icons/peter.ico`

Once the file is placed here, we will link it to `PyInstaller` during Phase 11 so that the final compiled `Peter.exe` natively displays your logo on the Windows Desktop and Taskbar.
